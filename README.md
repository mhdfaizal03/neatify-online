# Neatify Vehicle Care Website

A responsive, funky-premium storefront built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Vanilla JavaScript
- Bootstrap Icons
- Local uploaded product images

## Included
- Responsive navigation
- Hero product section
- Product catalog generated dynamically from JavaScript data
- Category filters
- Sorting
- Product search
- Product quick-view modal
- Add-to-cart flow
- Quantity controls / remove / subtotal
- Demo checkout action
- Exterior cleaning process section
- Exterior bundle section
- Interior Care "Coming Soon" feature
- Interior launch notification modal
- FAQ accordion
- Reviews / social proof section
- Newsletter form interaction
- Mobile-friendly responsive layout

## Run
Open `index.html` directly in a browser, or use a local server.

Example:
python3 -m http.server 8000

Then visit:
http://localhost:8000

## Production integration points
1. Replace demo checkout in `script.js` with Razorpay/Stripe/backend checkout.
2. Connect newsletter and interior notification forms to your API.
3. Add real inventory/stock data.
4. Add authentication/order history if required.
5. Add shipping/tax logic.
6. Replace placeholder social/footer links with real URLs.
